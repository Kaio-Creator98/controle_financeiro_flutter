# Ambiente de Desenvolvimento

Este projeto foi versionado no GitHub e ajustado utilizando Visual Studio Code dentro do GitHub Codespaces.

O ambiente solicitado foi utilizado para abrir o projeto, revisar a estrutura de pastas, validar a organização em MVVM e realizar ajustes finais no repositório.

Tecnologias utilizadas:

- Flutter
- Dart
- Provider
- Visual Studio Code
- GitHub Codespaces
- Arquitetura MVVM
